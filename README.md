# **1. Project Name and Description**

**System:** Step Up Increment Monitoring and Notification System (SIMNS)
**Client/Target:** Bureau of Internal Revenue (BIR) Regional Office, Caraga
**Course:** CSC 106: Software Engineering - Caraga State University (BSIT)

**Description:** SIMNS is a frontend prototype designed to automate and track salary step increments for employees. The system uses a logic-driven dashboard to calculate eligibility based on the employee's date hired and last step-up date. This prototype is built using HTML, CSS, and JavaScript, utilizing the browser's `localStorage` to simulate a working database for demonstrating core workflows, including employee data entry, automated notifications, and audit logging.
